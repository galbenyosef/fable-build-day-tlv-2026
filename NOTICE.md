# Notice: the data is the municipality's

The MIT licence in [LICENSE](LICENSE) covers the code in this repository and nothing else.

The repository contains no municipal data. At runtime the app reads the public GIS services of the Tel Aviv-Yafo Municipality (`gisn.tel-aviv.gov.il`): addresses, buildings, building permits, statutory plans and their documents, and the orthophoto (aerial photo) tiles. The floor counts that the model reads from permit text are derived from that data.
